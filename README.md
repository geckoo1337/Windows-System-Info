# Windows-System-Info
A script to get information about PC and devices. **wbemuuid.lib** is a Windows SDK import/static library for WMI COM identifiers. In practice, it is used when writing C++ code that communicates with WMI (Windows Management Instrumentation) through headers such as **wbemidl.h**. This allows you to collect a large amount of information about your PC, including its configuration and connected devices, which can be very useful. Finally, you can save all console output into a single file.

**25 categories** (CPU, RAM, HD, Monitor, OS and more more more) - hundred detailled informations :)
